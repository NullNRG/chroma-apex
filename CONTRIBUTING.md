# Contributing

Run tests locally (`make test`) and include raw benchmark methodology plus a correctness proof or invariant for algorithmic changes. Never claim an unconditional speedup from one input distribution. Do not commit upstream competitor implementations, secrets, benchmark binaries, megabyte temporary datasets, or third-party licensed code without explicit license review.

The project does not use GitHub Actions; contributors can run CTest, Go test, Python unittest and the Node suite locally. Security reports should describe the affected API and reproducible input without including personal records.
